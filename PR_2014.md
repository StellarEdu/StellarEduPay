## Summary

`GET /health` and `GET /health/ready` are unauthenticated probes, but each call ran `checkStellar()` → `horizonClient.call(server => server.ledgers().limit(1).call())` against live Horizon. A load balancer, container healthcheck, uptime monitor — or an attacker looping requests from many IPs — could therefore burn the same Horizon allowance that payment ingestion needs, and add Horizon latency to probe latency.

This change makes Horizon status a short-lived, process-wide cached value:

- `runStellarProbe()` is the only path that performs the Horizon request. It reserves one token from `sharedPollBudget` (so probes are finally counted in the budget stats) and updates `horizon_up` once per probe.
- `refreshStellarCache()` coalesces all concurrent refreshes into a single in-flight promise.
- `checkStellar()` serves the cached result for 15–30 s (`HEALTH_HORIZON_CACHE_TTL_MS`, default 20 s) and only starts a probe if the cache is cold.
- `startHorizonHealthCache()` / `stopHorizonHealthCache()` run a background refresher (warmed immediately, `unref`'d interval), wired into app startup and graceful shutdown. In normal operation anonymous requests never reach Horizon.
- If the shared budget is exhausted, no Horizon call is made: the last result is served flagged `stale` (or `status: unknown` on a cold cache, which keeps the HTTP code at 200/degraded).
- The detailed, live check remains available only on the admin-authenticated `GET /api/admin/health/details` via `buildHealthReport({ freshStellar: true })`; Horizon still does not affect readiness (#2013).

## Acceptance criteria

Added `backend/tests/issue2014-healthHorizonCache.test.js` with a counting Horizon mock:

- **1,000 concurrent `GET /health` requests cause exactly 1 Horizon call** (was 1,000).
- Concurrent cold-cache callers share one in-flight probe.
- The background refresher refreshes on the cache interval and consumes exactly one budget token per probe; stopping it stops the calls; 500 requests between ticks add zero calls.
- `/api/admin/health/details` still performs a live probe while `/health` keeps reading the cache.
- An exhausted budget makes zero Horizon calls.
